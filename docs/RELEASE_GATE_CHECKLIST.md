# Welian v1.0.5 发布阻断门验证清单

> 对应 SPEC_WELIAN_NEXT.md 第8.3节
> 真机验证：在小程序中逐项操作并打勾
> 自动化测试已覆盖门3/7/8，此处只列需真机验证的门

## 门1：登录→激活→记录互动→生成Action→确认完成

- [ ] 打开小程序，自动登录成功（不被困在登录页）
- [ ] 跳过/返回不触发 onboarding 死循环
- [ ] 添加3位联系人（姓名+关系类型），提交后返回 first_advise
- [ ] Dashboard 显示一张基于真实联系人的 Action 卡
- [ ] Action 卡可选"拟稿/已完成/稍后/跳过"
- [ ] 点击"已完成"→确认→北极星计数+1（查 /data/metrics）
- [ ] 首个价值时间 < 3分钟

## 门2：多入口写入同一事件口径

- [ ] 直接创建待办（todos 页）→ 完成 → 检查 trackAction 事件
- [ ] 聊天中"记一下今天和老许聊了XX" → 确认 → 检查 interaction_recorded 事件
- [ ] 创建会议 → 自动生成参会待办 → 完成 → 检查 todo_completed 事件
- [ ] Action 卡点"已完成" → 检查 action_card_done + interaction_recorded
- [ ] 所有事件都有 event_id、source、occurred_at

## 门4：数据损坏不覆盖 + 恢复演练

- [ ] 手动破坏 KV 中 todos 数据（JSON 格式错误）→ 操作不覆盖原数据
- [ ] 联系人/互动/待办定期快照存在（查 KV snapshot: 前缀）
- [ ] 用户全量导出可用（GET /data/contacts + /data/timeline + /data/todos）
- [ ] 多数据集操作部分成功有重试语义

## 门5：感知确认/拒绝/撤销 + 分享身份同意

- [ ] 采集 GitHub 感知 → 确认 → 写入 contact memories
- [ ] 确认后 Dashboard 出现 perception_driven Action
- [ ] 拒绝感知 → status=rejected，不写 memories
- [ ] 删除感知 → 撤销成功
- [ ] 分享链接不隐式绑定双方身份

## 门6：通知偏好/静默/每日上限/重复触发

- [ ] 关闭某类通知偏好 → 定时任务不发送该类
- [ ] 设置静默时段 → 静默期内不发送
- [ ] 设置每日上限 → 超过上限不发送
- [ ] 同一 dedupeKey 重复触发 → 只发送一次
- [ ] 渠道失败有日志记录

## 门9：无未经确认的自动社交行为

- [ ] 代码中无自动发消息逻辑
- [ ] 代码中无自动点赞逻辑
- [ ] 代码中无自动加好友逻辑
- [ ] 所有社交行为需用户确认
